# Changelog

## Unreleased

- `ragbench faithfulness`: splits generated answers into claims, asks a judge whether
  the retrieved contexts support each one, and reports the share of supported claims
  with a bootstrap 95% interval. With human labels in the answers file it also reports
  the judge's agreement with them (ROC AUC and accuracy).
- `ragbench.judges:TokenOverlap`: a dependency-free lexical baseline judge.
- The command line reports a misspelled `module:Name` as an error instead of a traceback.
- `Hybrid` retriever: reciprocal rank fusion of BM25 and Dense (`rrf_k=60`).
- `Rerank` retriever: a fastembed cross-encoder over the top hits of a BM25, Dense or
  Hybrid first stage.
- `cache=<dir>` for Dense, Hybrid and Rerank: the corpus embedding is saved once per
  model and corpus and reused.
- The benchmark runs Hybrid and Rerank too, one job per dataset, and the README shows
  one paired comparison per pair of runs.

## 1.1.1 (unreleased)

- The distribution is renamed `ragbench-eval`, because PyPI refuses `ragbench` as too
  close to the existing `rag-bench` project. The import name and the `ragbench` command
  are unchanged.

## 1.1.0 (2026-11-27)

- `ragbench gate`: compares a candidate run with a baseline on the same queries and
  exits 1 when a metric drops by more than `--max-drop`, judged on the mean change or,
  with `--mode ci`, on the whole 95% interval. Runs that differ in split, depth, nDCG
  cutoff or identical-id handling are refused. Writes a Markdown summary to
  `$GITHUB_STEP_SUMMARY` when set.
- `action.yml`: a GitHub Action that runs the candidate retriever and the gate, so a
  pull request fails when retrieval quality drops below a committed baseline.

## 1.0.0 (2026-11-27)

First stable release.

- BEIR loader (`corpus.jsonl`, `queries.jsonl`, `qrels/<split>.tsv`) and `ragbench download`,
  with a Hugging Face fallback when the UKP mirror is unreachable.
- Metrics: nDCG@10 (linear gains, matching trec_eval `ndcg_cut.10`), Recall@10, Recall@100,
  MRR@10, cross-checked against pytrec_eval in the tests.
- Seeded percentile bootstrap intervals for every mean, and a paired bootstrap for
  comparing two runs on the same queries.
- Retriever protocol: any object with `search(query, k)`, loaded from `module:Name` or
  `file.py:Name`, with optional `index()` and `search_batch()`.
- Built-in retrievers: Lucene-style BM25 (optional Snowball stemming) and a dense
  retriever over fastembed embeddings.
- CLI: `download`, `info`, `run`, `compare`, `report`.
- Benchmark results on SciFact, NFCorpus and ArguAna, generated by
  `scripts/benchmark.sh` and committed unedited under `results/`.
